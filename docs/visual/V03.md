# SIMUL-ANDE Visual v0.3

Actualización incremental de React + TypeScript + Phaser 3 en `prototype/visual-phaser`, directorio `visual/`. Conserva entrevista, exploración, inventarios, TX01, referencia, RX/laboratorio, bitácora, evaluación y exportación. No modifica el MVP Python, `main` de GitHub ni la presentación académica de GitHub Pages.

## Funciones

- Estación técnica con tipografía de sistema monospace, paneles rectangulares, azul petróleo, alertas textuales y entorno blanco/mostaza. Sin fuentes ni ilustraciones remotas.
- Monitor dibujado dentro de Phaser y equivalente semántico accesible bajo la sala. SpO₂, FC, FR, PA, temperatura y estado de soporte. Los valores no medidos aparecen pendientes. No se dibuja ECG ni señal fisiológica continua.
- Fuente local o independiente de transporte, comprobación operativa, dispositivo, flujo habilitado en el guion, inicio, detención, nueva oximetría y comprobación de reserva. Las selecciones quedan en la bitácora con su valor; un ID repetido nunca vuelve a ejecutar o consumir.
- Contexto visible y persistente durante la interacción: categoría, ubicación no consignada, 100 m s. n. m., turno, personal, recursos, medicamentos, movilización y tiempo al hospital. En escritorio permanece al desplazar la página; en móvil se coloca después de la sala para mantenerla como primera superficie de trabajo.

## VM-06 · revisión médica pendiente

`visual/src/data/case.json` incorpora `oxygen_simulation`; los datos originales de paciente, altitud y recursos se conservan. `spec/` y `data/` originales permanecen intactos. La localidad no tiene nombre en el caso: se identifica como no consignado.

Las combinaciones de controles son **datos ficticios del ejercicio**, sin aprobación clínica. Los guiones NAC-DEMO-A y NAC-DEMO-B contienen resultados explícitos (94 % y 89 %) tras cinco minutos docentes y una nueva medición. Se muestran como SIMULADOS y pendientes de VM-06. No son predicciones ni una regla flujo–SpO₂, ni objetivos terapéuticos. No se interpolan otras combinaciones: se muestra «Respuesta no validada». Antes del tiempo escrito se muestra «Reevaluación pendiente». Retirar soporte no restaura automáticamente una lectura basal de 88 % como nueva medición.

No se introducen recomendaciones definitivas sobre flujo, técnicas o metas. VM-06 debe revisar fuentes clínicas verificables, compatibilidad/dispositivos, restricciones de los controles, guiones numéricos, intervalo docente, respuesta insuficiente y política logística de reserva antes de uso curricular clínico. Ninguno de estos guiones tiene validación médica concluida. VM-01–VM-05 y TX01/VM-03 siguen pendientes.

La autonomía disponible está expresada únicamente en minutos en el caso. Se descuentan minutos docentes de soporte, sin inferir presión, litros del cilindro ni consumo proporcional al flujo. La recarga no avanza tiempo y comprobar reserva no la descuenta. La autonomía es una simplificación logística ficticia que también requiere VM-06.

La variante `empty` deja vacía solo la fuente local de ese intento; el guion base sigue operativo. Registra la falla y permite coordinar, esperar movilización y comprobar el soporte independiente del transporte. Este solo se puede activar después de la llegada docente y con equipo entrenado/oximetría. No permite preparar una salida sin soporte. Se comprueban reserva para movilización y viaje, entrevista, mediciones, receptor y entrega actualizada. Una SpO₂ simulada mejor no elimina estos requisitos ni demuestra estabilidad. La finalización significa **transferencia preparada**, nunca traslado realizado o recuperación.

## Persistencia

Estado v3 en `simul-ande:visual:v3`, validado con Zod e invariantes de dispositivo, flujo, soporte, lecturas, reservas, stock y eventos. Se migra automáticamente v2 conservando entrevista, exploración, medicamentos y bitácora. La clave v2 permanece intacta como respaldo. El soporte antiguo no tenía configuración verificable: se desactiva, se invalida la entrega y se informa que debe configurarse de nuevo. Un intento ya terminado sigue terminado, como registro histórico. Datos corruptos se reinician con aviso; si el almacenamiento falla, el intento continúa en memoria y puede exportarse.

La evaluación es formativa y local; no es una certificación ni un sistema contra manipulación.
